Bijective Projection Shell — WASM demo

Real PrismCage construction (SIGGRAPH Asia 2020) compiled to WASM. CGAL, geogram, embree, HDF5, and TBB have been replaced with Shewchuk's robust predicates, libigl AABB, and the in-source spatial-hash self-intersection module. Bijective Phong projection is run on each query point lying inside the prismatic shell.
